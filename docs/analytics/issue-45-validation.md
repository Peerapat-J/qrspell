# Analytics security and network verification (#45)

Prepared on 2026-09-29. Implementation and automated verification are recorded
here; manual checks and production approval remain separate gates. The public
Privacy Policy covers the QRSpell macOS app.

## Provider and data-handling record

- Cloudflare measures observed public-route traffic and performance. The local
  loader permits only the production origin, outside webdriver contexts, with
  an empty, origin-only or registered same-origin public referrer. Credentials,
  query/fragment and other paths suppress the external beacon. SPA tracking is
  disabled on every page. These exclusions make its counts incomplete.
- PostHog uses the pinned vendored SDK and EU ingestion origin, memory-only
  cookieless mode, no person profiles, no persistent browser storage, and no
  automatic capture, replay, exceptions, flags or external dependency loading.
  DNT/GPC and offline signals prevent initialization/capture. Local/test/preview
  contexts cannot initialize the deployed production configuration.
- Only the schema-v1 event/property enums are approved. Before-send sanitization
  removes automatic enrichment and rebuilds the transport fields. QR content,
  center text/images, filenames, clipboard data, generated bytes, full URL/query/
  fragment, raw referrer/error and local deduplication hashes are not product
  event properties.
- Provider region, retention, processing limitations and DPA/subprocessor review
  remain documented in [architecture-v1.md](architecture-v1.md) and the historical
  [sandbox-validation.md](sandbox-validation.md). This run does not reverify live
  project settings, retention or delivery. Production review must do that before
  approval; the contract caps product-event retention at 12 months.
- Product Analytics remains disabled with an empty production token. This work
  does not enable or deploy tracking.

## Automated coverage

The browser suite intercepts every external request. It uses fake sandbox
configuration/tokens and simulates the production origin only in the served
Cloudflare loader fixture; the deployed loader itself is also tested to refuse
localhost. No analytics request reaches a provider during these tests.

- All seven HTML routes enforce the exact CSP and `no-referrer`; the Generator
  alone permits its required inline styles and data/blob images. Mutation tests
  reject missing/duplicate policies, broad/unrelated origins and unsafe scripts.
- The real vendored PostHog SDK and Cloudflare probe run together through
  production Generator call sites. Every final request URL, controlled header
  and POST body is inspected. Missing CDP bodies are recovered from byte entries
  or explicitly retrieved; missing evidence fails the audit. Raw, JSON-escaped,
  percent-encoded and offset base64 canaries are checked.
- Canary inputs cover QR content, center text, image bytes/data URL, filename,
  page query/fragment, incoming referrer path/query and raw error. A source using
  an unsafe referrer policy is simulated to ensure the browser really supplies
  the private referrer to the guard. The rejected referrer prevents the external
  Cloudflare script request while product events and Generator actions continue.
- Existing tests cover unknown events/properties/values, URL/UTM filtering,
  empty browser storage, local/test origins, DNT/GPC, failed optional modules,
  capture throws/rejections, blocked endpoints, timeout and HTTP 400/503. Native
  keyboard/pointer App Store navigation, Gallery, Help Center copy controls and
  Generator Verify/Copy/Download/Reset are exercised under the new CSP.
- Clipboard writes are stubbed and downloads are initiated then denied. These
  tests prove UI/network behavior, not physical clipboard/disk behavior or
  delivery to a real provider.
